# Focus: Visual Enhancement with Zero Performance Drop
# Principle: Images should guide, not distract.

## 1. IMAGE LOADING STRATEGY
- **Lazy Loading:** Semua gambar wajib menggunakan `loading="lazy"` agar tidak menghambat render awal.
- **Next-Gen Format:** Gunakan format `.webp` atau `.avif` untuk kompresi maksimal.
- **Placeholder:** Gunakan blur-up effect atau solid color placeholder selama gambar asli di-download.

## 2. COMPONENT VISUAL HIERARCHY
- **Recipe Title:** Gunakan font size besar (h1) dengan sedikit bayangan lembut (drop shadow) agar terlihat premium.
- **Steps Illustration:** Daripada foto, gunakan ilustrasi garis (Line Art) yang sangat ringan untuk menggambarkan teknik masak (misal: icon panci berasap).
- **AdSense Integration:** Beri border halus pada area iklan agar user tahu itu iklan, tapi tetap selaras (seamless) dengan desain web.

## 3. COLOR PSYCHOLOGY FOR UX
- **Action Buttons:** Gunakan warna kontras tinggi (seperti Clementine Orange) untuk tombol "Masak Sekarang".
- **Success States:** Gunakan warna hijau lembut saat user berhasil mencentang semua bahan.
